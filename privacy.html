Privacy Policy

Last updated: November 7, 2026

1. About the app

Shorts Factory is a private tool operated by a single person to create and upload original animated Shorts to their own YouTube channel. It is not offered to the public.

2. Use of YouTube API Services

Shorts Factory uses YouTube API Services. By using Shorts Factory you agree to be bound by the YouTube Terms of Service. Google's collection and use of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

3. Data the app accesses, collects and stores

With the channel owner's permission, granted through Google OAuth, the app accesses:

  • youtube.upload: to upload videos, titles, descriptions and tags to the owner's channel.
  • youtube.readonly: to read the owner's channel and video details.
  • yt-analytics.readonly: to read the owner's channel performance metrics (views, watch time, retention).

It also reads public video statistics (titles, view, like and comment counts) through the YouTube Data API and public Google Trends data to find trending topics. It does not collect personal information about other YouTube users.

4. How data is used

Data is used only to research topics, publish the owner's own videos and measure their performance.

5. Sharing

Data is not sold, shared, disclosed or transferred to any third party.

6. Storage

OAuth tokens and collected statistics are stored locally on the owner's computer. The app does not use cookies and does not store information on any user's device or browser.

7. Data retention and deletion

  • YouTube API data stored by the app is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
  • When access is revoked, all stored tokens and YouTube API data are deleted within 7 days.
  • You can request deletion of any stored data at any time by emailing arisaza1489@gmail.com. Requests are completed within 7 days.

8. Revoking access

You can revoke the app's access to your data at any time through the Google security settings page: https://security.google.com/settings/security/permissions.

9. Changes

Changes to this policy are published on this page with a new "Last updated" date.
