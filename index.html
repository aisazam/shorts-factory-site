Shorts Factory

Shorts Factory is a private, single-user tool that produces original animated cartoon YouTube Shorts in English and Spanish and uploads them to its owner's own YouTube channel.

It uses the YouTube Data API to read public video statistics for trend research, to upload videos to the owner's channel, and the YouTube Analytics API to read that channel's own performance metrics. Only the channel owner authorizes and uses the app.
